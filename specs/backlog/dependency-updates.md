# Monter automatiquement les versions des dépendances

## Contexte

Les dépendances du dépôt ne changent de version que quand un développeur y pense.

## User story

En tant que développeur, les nouvelles versions des dépendances du dépôt me sont proposées automatiquement, sans avoir à les chercher.

## Critères d'acceptation

1. Quand une nouvelle version d'une dépendance du dépôt est publiée, une mise à jour vers cette version est préparée automatiquement, et un développeur décide de l'intégrer ou non.
2. La montée de version automatique est documentée dans `CLAUDE.md`.
