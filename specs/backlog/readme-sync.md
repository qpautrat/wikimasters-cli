# Tenir le README à jour

## Contexte

Le README présente chaque commande et l'installation. Sans règle, une commande ajoutée, modifiée ou retirée le rend faux sans que rien ne le signale.

Dépend de : [Présenter le dépôt dans un README](../readme.md).

## User story

En tant que développeur qui découvre le dépôt, le README que je lis décrit les commandes et l'installation telles qu'elles sont.

## Critères d'acceptation

1. `CLAUDE.md` impose de mettre à jour le README dans le commit qui ajoute, modifie ou retire une commande, ou qui change l'installation.
