# Tenir le README à jour

## Contexte

Le README présente les commandes, les options globales, les codes de sortie, la connexion, les fichiers qui gèrent la session et l'installation. Sans règle, un changement de l'un d'eux le rend faux sans que rien ne le signale.

Dépend de : [Présenter le dépôt dans un README](readme.md).

## User story

En tant que développeur qui découvre le dépôt, le README que je lis décrit le dépôt tel qu'il est.

## Critères d'acceptation

1. `CLAUDE.md` impose de mettre à jour le README dans le commit qui change ce qu'il décrit : une commande, une option globale, un code de sortie, la connexion, un fichier qu'il nomme ou l'installation.
